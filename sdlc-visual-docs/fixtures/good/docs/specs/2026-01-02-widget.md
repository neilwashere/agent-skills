# Spec: widget

## C1: widget wire format

Consumers bind to the frame layout; freezing it is the irreversible part.

## S1: p95 read latency under 10ms

Pass: benchmark harness reports p95 < 10ms warm. Fail otherwise.

## S2: unsigned payloads are rejected

Pass: a payload without a valid signature returns an error frame and is not
cached. Fail: it is served or cached.
