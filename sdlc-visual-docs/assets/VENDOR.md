The pin is what makes diagram rendering repeatable. Bumping this file is a
deliberate act: re-verify the offline render check (a `mermaid` fence
produces an SVG with the page opened from disk and the network disabled),
update the version, hash, and fetch date here, and mention the bump in the
commit message. The bundle is ~2.7 MB and is inlined into every rendered
page; that is an accepted cost for self-contained, offline artefacts.
